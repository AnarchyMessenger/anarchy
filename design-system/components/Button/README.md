Buttons: primary, secondary, ghost, danger; 34px, or 28px with `.sm`.

Use at most one `.primary` per view (Send invite, Join call, Request access). Use `.ghost` for icon-only header tools, always with an `aria-label`, and `.danger` for Revoke, Delete and Leave. Labels are sentence-case verbs. Luna turns these into bevelled gradient buttons with no change to the markup.
